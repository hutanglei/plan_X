# 创新药上市时间三档估算框架

基于药品市场经验，对任一创新药管线给出**顺利 / 正常 / 拖延**三种情形下的预期上市时间，并标注拖延风险点。本框架为量化估算，非精确预测，实际进度须以公司公告为准。

## 强制使用规则

**凡涉及"某药物何时能上市""离上市还有多久""管线兑现节奏""预期差"等时间预判时，必须按本框架输出三档时间，禁止只给单一时点。**

## 第一步：先校准真实日期

涉及"已发生/未发生"判断时，必须先调用 `get-current-date` 技能获取真实日期，禁止使用环境注入日期。

## 第二步：行业经验时长基准（核心参数）

以下为中国NMPA与美国FDA双体系的经验值，用于阶段转换耗时估算：

### 国内（NMPA）阶段转换时长

| 阶段转换 | 顺利 | 正常 | 拖延 |
|---------|------|------|------|
| Pre-IND->IND获批 | 2月 | 3月（60工作日） | 6月+（发补） |
| I期启动->I期完成 | 8月 | 12月 | 18月+ |
| I期完成->II期启动 | 3月 | 6月 | 12月+ |
| II期入组->数据读出 | 12月 | 18月 | 24月+ |
| II期完成->III期启动 | 6月 | 12月 | 18月+ |
| III期入组->数据读出（肿瘤） | 18月 | 24月 | 36月+ |
| III期入组->数据读出（慢病/自免） | 24月 | 30月 | 48月+ |
| III期数据->NDA递交 | 3月 | 6月 | 12月+ |
| NDA受理->获批（优先审评） | 6月 | 9月 | 15月+（发补） |
| NDA受理->获批（常规） | 12月 | 15月 | 24月+（发补） |

### 美国（FDA）阶段转换时长

| 阶段转换 | 顺利 | 正常 | 拖延 |
|---------|------|------|------|
| IND->I期首例入组 | 1月 | 2月 | 4月+ |
| III期数据->BLA/NDA递交 | 3月 | 6月 | 12月+ |
| BLA/NDA受理->获批（优先/突破性） | 6月 | 8月 | 12月+（CRL） |
| BLA/NDA受理->获批（标准） | 10月 | 12月 | 18月+（CRL） |

### 加速审批路径时长基准（⭐ 必须并列考虑）

并非所有品种都需走"完整III期->NDA"线性路径。满足以下条件之一者，应**并列评估"附条件批准/单臂II期报产"加速路径**，其上市时间可比完整III期路径快1-2年：

| 加速路径 | 适用条件 | 阶段转换时长（顺利/正常/拖延） |
|---------|---------|------------------------------|
| **附条件批准（NMPA）** | 严重危及生命且无有效治疗手段/罕见病；II期数据ORR显著优于现有疗法 | II期数据->NDA递交:3/6/12月；NDA受理->附条件获批:4/6/12月 |
| **单臂II期报产（NMPA）** | 罕见突变/难治复发；ORR≥阈值且有剂量依赖；参照同类已批先例 | II期数据->NDA:3/6/12月；优先审评获批:4/6/12月 |
| **加速批准/突破性（FDA）** | Breakthrough/RMAT/Fast Track；替代终点有望预测临床获益 | II/III期数据->BLA:3/6/12月；受理->加速批准:6/8/12月 |
| **滚动提交（Rolling Submission,FDA）** | 获Breakthrough/Fast Track资格，可分模块递交 | BLA各模块分批提交，整体等待期压缩2-3月 |

**判定要点**：估算前须先核实该管线是否已纳入突破性疗法/附条件批准通道，以及是否已有亮眼II期数据（高ORR）。若满足，顺利档与正常档应优先采用加速路径时长，完整III期路径仅作为拖延档兜底。

### 头部Biotech加速因子（须动态下调基准）

对头部Biotech+MNC合作标的，行业平均基准（含中小Biotech拖慢案例）会系统性偏保守，应允许：
- **入组时长**：大适应症/多中心并行/患者池大 -> 取"顺利档"而非"正常档"作为正常预期
- **多线并行取最快**：若多项III期并行，以最早读出那条报产，不等所有III期完成
- **审评时长**：已有突破性疗法/创新信誉的申办方，NDA审评选顺利档
- **靶点风险动态化**：靶点历史失败率须结合最新临床数据动态调整，已有亮眼数据后下调风险权重（不可机械套用历史）

## 第三步：三档情形定义

| 情形 | 含义 | 适用场景 |
|------|------|---------|
| **顺利** | 各阶段转换均取经验下限，无发补/无方案调整/入组顺利 | 乐观定价基准 |
| **正常** | 各阶段转换取中位经验值，含常规审评排队 | 基准预期 |
| **拖延** | 取经验上限，含发补/CRL/入组缓慢/方案调整/竞争恶化 | 风险情景，预期差来源 |

## 第四步：估算推算链（必须透明）

对每条管线，按"当前节点 + 剩余阶段转换 + 各阶段经验时长"累加，给出三档时间。**必须写出推算链**，例如：

```
当前：III期2025-05首例入组
顺利：入组18月(2026-11) -> 数据6月 -> NDA递交(2027-05) -> 优先审评6月 -> 获批(2027-11)
正常：入组24月(2027-05) -> 数据6月 -> NDA递交(2027-11) -> 优先审评9月 -> 获批(2028-08)
拖延：入组36月(2028-05) -> 数据12月 -> NDA递交(2029-05) -> 发补15月 -> 获批(2030-08)
```

## 第五步：拖延风险点标注（必须）

每条管线必须列出**2-3个具体拖延风险点**，常见风险类型：

| 风险类型 | 示例 |
|---------|------|
| **入组缓慢** | 罕见突变患者基数小、竞争试验多 |
| **终点复杂** | MASH/NASH、阿尔茨海默等终点主观性强 |
| **靶点历史失败率高** | DLL3、Aβ等历史失败案例多 |
| **发补/CRL** | CDE要求补充数据、FDA发完全回复信 |
| **竞争恶化** | 同类竞品抢先上市、改变标准疗法 |
| **BD不确定性** | License-out方行权与否、合作方推进优先级 |
| **监管政策** | 临床暂停、适应症收窄要求 |

## 第六步：已上市品种处理

- 若核心适应症**已获批上市**：三档时间均填"已上市(年-月)"，差异在新适应症节奏
- 新适应症按"III期推进->数据->NDA->获批"单独估算

## 输出格式

对每条管线输出：

```
管线：[公司] [品种] ([靶点/模态])
当前阶段：[精确子状态]
剩余步骤数：[0-4]
顺利上市：[年月]  推算链：...
正常上市：[年月]  推算链：...
拖延上市：[年月]  推算链：...
拖延风险点：1)... 2)... 3)...
估算依据：[完整推算链透明展示]
```

## 使用示例

### 示例：百利天恒 BL-M14D1（DLL3 ADC）-- 纳入加速路径

```
当前阶段：III期刚启动（2026-06-05 BL-M14D1-LC-301）；2026 ASCO二线ES-SCLC ORR78.6%
剩余步骤数：3（加速路径） / 4（完整III期路径）
加速路径判定：ORR78.6%亮眼+罕见瘤种+对标疗法 -> 符合附条件批准/单臂报产条件
顺利上市：2028下半年
  推算链(加速)：II期数据已读出 -> 单臂II期报产NDA(3月) -> 附条件批准(4月) -> 2028获批
正常上市：2029上半年
  推算链(加速)：II期补充数据->NDA(6月)->优先审评(6月)->2029获批
拖延上市：2031
  推算链(完整III期兜底)：III期入组3年->数据->BLA->FDA审评12月->2031；含发补/适应症收窄
拖延风险点（动态化）：
  1) DLL3历史失败率高（但ADC形态与CAR-T/双抗机制不同，且ORR78.6%已部分证伪此风险，下调权重）
  2) 小细胞肺癌入组竞争激烈
  3) FDA可能要求额外安全性数据
```

## 注意事项

1. **行业经验非精确预测**：本框架基于历史平均，单药可能显著偏离，须标注"估算非预测"。
2. **肿瘤 vs 慢病差异大**：肿瘤III期通常18-24月，慢病/自免可达30-48月，必须按适应症类型选基准。
3. **海外比国内慢**：FDA BLA审评通常比NMPA NDA审评多2-4月，海外品种须单独估。
4. **优先审评须确认**：是否纳入优先审评/突破性疗法直接影响审评时长，须核实。
5. **定期刷新**：管线进展更新后须重估，尤其是III期入组进度变化时。
6. **与 critical-analysis-framework 联动**：对含预测的分析做批判式审视时，可用本框架检验其时间假设是否合理。
