# PDF 财报三张表提取

从中文 A 股年报/半年报 PDF 中提取合并资产负债表、合并利润表、合并现金流量表及关键附注明细。输出结构化文本供下游分析（如 mjh-financial-analysis）使用。

## 前提

- 输入为 A 股公司正式披露的 PDF（非扫描件，可复制文字）。扫描件不适用。
- 依赖 `pymupdf`（`pip install pymupdf`）。`pdftotext` 通常不可用，不要尝试。

## 工作流

### 第 0 步：提取全文

运行 `scripts/extract_pdf_text.py <input.pdf> [output.txt]`，生成带 `===== 第N页 =====` 标记的 UTF-8 纯文本。

教训（本项目实测）：
- macOS 默认无 `pdftotext`，先 `python3 -c "import fitz"` 确认 pymupdf 可用再提取。
- 输出文件放在 PDF 同目录或 /tmp，命名为 `<原名>.txt`，不要覆盖原 PDF。

### 第 1 步：定位三张表

在提取出的 .txt 上用 Grep 搜索表头关键词，拿到行号后用 Read 读取对应区间：

```
Grep: 合并资产负债表|合并利润表|合并现金流量表
```

- 取**合并口径**（不要母公司口径），除非用户明确要求母公司。
- 合并资产负债表通常跨 2-3 页，Read 时把区间放宽到包含流动资产+非流动资产+负债+所有者权益完整段。
- 期初+期末两列数据都要，同比分析依赖期初。

### 第 2 步：提取核心科目

按 mjh-financial-analysis 最低数据要求逐项提取。资产负债表必取：货币资金、应收票据、应收账款、预付款项、其他应收款、存货、固定资产、在建工程、无形资产、商誉、递延所得税资产、短期借款、应付票据、应付账款、合同负债、其他应付款、一年内到期的非流动负债、长期借款、应付债券、长期应付款、总资产、净资产、归母净资产、少数股东权益。

利润表必取：营业收入、营业成本、税金及附加、销售费用、管理费用、研发费用、财务费用（含利息费用/利息收入明细）、其他收益、投资收益、公允价值变动收益、信用减值损失、资产减值损失、营业利润、利润总额、所得税、净利润、归母净利润、少数股东损益、每股收益。

现金流量表必取：销售商品提供劳务收到的现金、经营活动现金流入/流出小计、经营净额、购建固定资产无形资产和其他长期资产支付的现金、投资净额、吸收投资收到的现金、取得借款收到的现金、偿还债务支付的现金、分配股利利润或偿付利息支付的现金、筹资净额、汇率变动影响、现金及现金等价物净增加、期初/期末现金及现金等价物。

### 第 3 步：按需挖附注明细

分析深入时需要附注支撑，常用定位关键词：

| 需要的信息 | Grep 关键词 |
|---|---|
| 货币资金受限情况 | `所有权或使用权受到限制的资产` |
| 有息负债构成 | `一年内到期的非流动负债`（看信用借款/租赁负债/应计利息拆分） |
| 应收账款账龄/前五名 | `按账龄披露`、`前五名`（应收 section 附近） |
| 应付股利 | `应付股利`（其他应付款附注内） |
| 控股股东质押 | `质押、标记或冻结情况`（股本结构 section） |
| 汇兑损益 | `汇兑`（非经常性损益 section + 风险 section） |
| 外销/内销拆分 | `国外销售`、`境外.*营业收入`（经营情况讨论 section） |
| 衍生品持仓 | `以套期保值为目的的衍生品投资` |
| 外币货币性项目 | `外币货币性项目`（附注末尾） |
| 前五大客户集中度 | `前五名客户`、`余额前五名`（信用风险 section） |

教训（本项目实测）：
- 附注行号分布广，先 Grep 拿行号再 Read，不要盲目顺序翻页。
- 表格型附注（如受限资产、衍生品持仓）数字常被 PDF 拆行，Read 时把上下文多读几行拼接。
- 有些关键信息在非财务章节：汇兑损益在"非经常性损益"说明里、外销占比在"经营情况讨论"里、质押在"股本结构"里，不要只在财务报表附注里找。

### 第 4 步：交叉验证

- 现金及现金等价物期末余额（现金流量表）≠ 货币资金（资产负债表）时，差额=受限资金+非等价物（如定期存款>3个月）。本次实测：货币资金 148.2 亿 vs 现金等价物 119.1 亿，差额 29.1 亿，其中受限仅 0.86 亿，其余为定期存款——属正常。
- 应收/应付票据+账款要与合同负债/合同资产联动看，判断"两头吃"能力。
- 汇兑损失大时，回到附注 61（外币货币性项目）核对美元/欧元敞口，验证损失规模是否合理。

### 第 5 步：输出结构化结果

把提取结果整理为：三张表核心科目（期末+期初两列）+ 关键附注明细（受限资金、账龄、前五名、质押、汇兑、衍生品、外销占比）。标注单位（元/万元）和口径（合并/母公司），交给下游分析 skill。

## 常见坑

1. **母公司口径混入**：资产负债表后半段是母公司口径，提取时认准"合并"二字，不要拿过母公司数据。
2. **半年度 vs 年度**：半年报应收/营收、周转天数等指标天然高于年报（半年营收只有全年一半），同比分析要用上年同期而非年初。
3. **表格拆行**：PDF 表格经 pymupdf 提取后，一个单元格的数字可能被拆成多行（如 `2,283,024,8` + `41.02`），拼接时注意千分位。
4. **页码标记干扰**：`===== 第N页 =====` 会打断连续表格，Read 区间要跨过页码行。
5. **单位混用**：正文用"万元"、报表用"元"，附注有的用"万元"。提取时标注清楚，计算前统一。
