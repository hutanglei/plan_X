# 这次是真的，以后房价不能再涨了，连一分钱都不能涨了！

中共中央政治局7月31日召开会议，其中会议要求：“下决心解决好房地产市场问题，坚持因城施策，促进供求平衡，合理引导预期，整治市场秩序，坚决遏制房价上涨。加快建立促进房地产市场平稳健康发展长效机制。”诸位，请注意，之前谈到房价都是“遏制房价过快上涨”，这次明确表示，“坚决遏制房价上涨”。这是第一次明确不让涨了，只能平或者跌。
四海八荒第一好色：听了个笑话[笑cry]。
Angel-迪丽热巴：扯蛋吧房价能降除非火星撞地球，大家都该炒房炒房 不会跌的 想啥呢。
马靖昊说会计：这次是真的，以后房价不会再涨了！！！
据西班牙《世界报》报道，中国的高房价毁灭了年轻人爱情，也毁灭了年轻人想象力。他们本可以吟诵诗歌、结伴旅行、开读书会。现在，年轻人大学一毕业就成为中年人，为了柴米油盐精打细算。他们的生活，从一开始就是物质的、世故的，而不能体验一段浪漫的人生，一种面向心灵的生活方式。
陈乌妹：两年前，我和男朋友在老家订了婚，但是耗到现在都没有结婚。其中原因，说到底就是因为一套房。父母说只要我男朋友在北京买了房，两人就可以立刻结婚。
马靖昊说会计：我建议乌妹，宁愿做房奴，也不要做婚奴。
任何一个正常的国家，涉及到民生的东西是不能用来炒作的，特别是不能炒房子，这些炒作行为过去称为"投机倒把"，是要受到严厉打击的。原因很简单，炒作最终会导致失控，会引发社会剧烈动荡。政府目前不会不知道炒房行为的严重后果，但长期依赖的土地财政让它如同吸食了鸦片一样，欲摆不能，这次真的要戒了，不然，真要“爽”到死吗？
朱南逸：在说瞎话，[允悲][允悲]调控了这么多年了，房价越调越高。
马靖昊说会计：这是中国最高决策层中央政治局发出的，是坚决命令戒“毒”的。以前是遏制房价过快上涨，留下了涨价的空间，这一次可是遏制房价上涨，字里行间都在说，你房价连一分钱都不能涨。
可以说，从这次政治局会议关于房地产的措词而言，可以看出高层已经对房价长期以来的非理性上涨已经忍无可忍了，用词异常严厉，显示出中国高层遏制房价的坚定决心。
李洪建V：土地价格，税金，建安成本，人工成本都涨，然后不让房价涨，这是那个经济学家的谬论。
马靖昊说会计：如果从完全性交易市场来看，你讲得很有道理，但中国楼市属于非完全性交易市场，是「政策市」，投机炒房客利用政策暴发，无良开发商利用政策大卖，贫困县房价破万都属于正常现象。但是，真理和理性永远是正的延续，否则便是灭亡，乱象也终究会被系铃人所整治。

进入2018年以来，关于房地产税相关政策出台的声音就越来越大。在2018年端午节前后，出了一条信息：全国统一的不动产登记信息管理基础平台，目前已实现全国联网。不动产登记的全国联网，让开征房地产税的条件更加成熟！
这次中央政治局会议强调，加快建立促进房地产市场平稳健康发展长效机制。这意味着作为长效机制重要内容的房地产税立法进程将加快，房地产税草案有可能会在2019年通过审议成为法律，2020年或先在一线城市和部分二线城市启动房地产税征收。
妄念長生：马老师，那征收房地产税后房价是不是会大跌？
马靖昊说会计：肯定不会。中央是“坚决遏制房价上涨”，征收房地产税并非要让房价大跌，房价大跌带来的风险恐怕大于大涨带来的风险，弄不好就搞得银行破产，引发金融危机。征收房地产税主要还是要解决土地资源逐步枯竭后，地方政府财政收入问题。但征收房地产税增加房屋的保有成本，增加“只炒不住”的成本，对于房价能起到一定的“稳定器”作用。
未来的房地产税决不应该与个税基本上对所有的劳动者收税一样对所有的有房者收税，为了避免在开征过程中引发社会矛盾，笔者有几条可操作性建议如下：
1.要利用好伟大的“代扣代缴”制度，将房地产税由直接税巧妙地转变为“间接税”，由房地产税负税人所在单位作为代扣代缴责任人，在工资中逐月按比例直接扣除。这可以最大限度降低拔鹅毛的痛感，将税痛化解于无形中！（注：你们可能要恨我提出这条建议，不过，下面的建议看了都挺舒服的。）
2.老百姓交纳的房地产税可以作为个人所得税的抵减项目。
3.征收的房地产税的使用范围应该明确规定，至少有一部分要用之于民，比如交纳了房地产税的老百姓可以免交小区的物业管理费，小区的基础建设可以考虑投入一点，让居住环境在纳税后能够有所提升。
4.要考虑好老百姓自住房的免税诉求，规定好一个免征面积空间，比如，三级城市人均80平米免征房地产税，二级城市人均70平米免征房地产税，一级城市人均60平米免征房地产税。
5.进一步减少财政供养人口数量， 据中国经济体制改革研究会副会长陈剑提供的一个数据是，到2014年年底，中国财政实际供养人数远超过6400万。有资料显示中国行政管理费用占财政总支出的比重估计接近或超过25%，对比经合组织国家（世界主要发达国家），其行政支出占财政支出的比重普遍要低于中国，各国基本都能控制在15%以下。因此，政府要认认真真搞精兵简政，将财政供养人数降下来，将行政支出占财政支出的比重降下来。
