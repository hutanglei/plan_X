# 既然说增值税的最终买单人是消费者，但为什么企业对税负重还这么有意见呢？大伙说说！

既然说增值税的最终买单人是消费者，但为什么企业对税负重还这么有意见呢？
因为增值税根本就不是价外税，而是价内税，必须通过价格从消费者那里得到弥补，但在老百姓购买商品承担增值税前，政府就已经将大部分增值税通过企业代收代缴收到了，因为下家的“进项税额”就是上家的“销项税额”，不过，如果税负重，企业弥补的难度会越来越大，所以企业会有意见，况且少交的增值税就是企业的利润。
再说如果企业的产品最终销售不出去，增值税的最终买单人就是企业自身。
汉舟：因为跟垄断国企不一样，民企没有定价权，贵了没人买，所以不能理直气壮把增值税的部分全部由消费者承担[挖鼻]。
Small-full：前提是能通过价格转嫁出去，现在民众的消费力都被房产医疗教育掏空，所以难转嫁了啊。
马靖昊说会计：购买材料就交了税，生产的产品烂在库存里卖不掉，企业就是最终承担者。付出的都是现金流，能没有意见吗？
andrea_liu：马老师，一直觉得增值税以价外税的形式征收非常不好，实质是虚增了没有实际现金流支持的利润，而其他流转税基本是价内税，为何增值税设计为价外税？
马靖昊说会计：中国的增值税本质上还是属于价内税，只是玩了一个价外计算的花招。不过，话说回来，价内税与价外税又有什么不同呢？所谓的价外税只是让老百姓在消费时就立即知道在价外还交纳了多少税，难道这些税就不是价格的组成部分吗？它与价内税的唯一区别就是显性与隐性的区别，价内税只是将税隐藏在价格中而已。再重申一句：税永远是价格的组成部分，这个世界从来就没有价外税，价外税只是数学游戏。
增值税的设计体现了一种狡猾的征税技巧，实质上，政府几乎将全部税收风险通过所谓的"代收代缴"转移给了企业。但由于给了企业一个“甜头”，规定在价格中的进项税额，未来是可以抵扣回来的，因此，企业有意见还真有点说不过去。
h行路：理论上是消费者承担，实际上是企业缴纳，而且这个必须有价格来补偿。且价格相对稳定的，增值税高了，利润就小了。
laosu18：因为增值税不在利润表，是最大的税金谎言。
你这么说增值税不在利润表是最大的税金谎言，还真有道理。大多数人以为增值税不影响企业的损益，实际上是其在会计处理上干的“好事”。由于增值税在计算上设计为“价外税”，按照这种设计，它的会计处理也配合得天衣无缝。可以说，增值税的会计处理实质上是配合税务另设了一套核算系统，它将部分收入(改姓为销项税额)和成本(改姓为进项税额)的核算放在损益核算体系之外，用于迷惑纳税人，这样税务切走的那一块就不在损益中核算了。

小糖果说的“毛利的16%”是一个近似的概念，其实如果从毛利的角度，增值税的税率应该比16%要高很多，我们知道，产品成本含三块：直接材料、直接人工、制造费用，一般只有直接材料能取得进项税。所以，产品的增值额=售价－材料成本。这样，增值额无异于被夸大了，对于税局而言，那是非要加上人工成本以及没有进项税的制造费用（有进项税的制造费用允许抵扣）才行的。交了税实际并没那么多增值，这是中国增值税的悲哀所在，也是中国制造业的痛苦之源。按“销项税减进项税”模式征增值税是有悖于设立增值税初衷，不公平，如果能够按照毛利征税，那是再好不过了。

在这里，再谈谈增值税税负率与毛利率的关系。
税局采取以取得增值税发票抵扣联并符合抵扣规定进行抵扣的措施征收增值税，生产产品投入的部分材料、工资、费用等不能取得增值税发票。故以毛利额征收的增值税不等于实际缴纳的增值税，但有一定的联系。
增值税税负率（以下统一称为“税负率”）=增值税额/销售收入
以毛利额推算增值额(税务)
增值额(税务) =[销售收入－（总销售成本－不可抵扣税的成本）]×16%
即：增值额(税务) = （毛利额+不可抵扣税的成本）×16%
税负率与毛利率的关系：
税负率 = （毛利额+不可抵扣税的成本）/收入×16%
税负率 = （毛利率+不可抵扣税的成本/收入）×16%
chivalryyy：实质是重复征税 。所得税及企业增值额增值税计税依据。
璠爷是喵女良：增值税 实际上就是在你把原材料加工商品过程中增值的部分征税 可以说是毛利税 在减去部分费用 还有企业所得税。
你们两个说得有道理。增值税是针对毛利额以及不可抵扣税的成本征税，而企业所得税是针对利润总额征税，二者税率都不低，同时征收可以想象企业承受的压力。实际上，同时征收增值税、所得税涉嫌重复征税，因为针对毛利额以及不可抵扣税的成本征完16%的增值税后，再扣除期间费用以及营业外支出等，又征收了25％的所得税，因此，属于重复征税。
