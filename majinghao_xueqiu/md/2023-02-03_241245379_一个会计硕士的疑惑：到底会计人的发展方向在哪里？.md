# 一个会计硕士的疑惑：到底会计人的发展方向在哪里？

1980年5月，一封署名“潘晓”的读者来信《人生的路呵，怎么越走越窄……》发表在《中国青年》杂志上，文章用沉重、幽怨、郁闷、诚挚、激愤的笔触书写了人生的痛苦和创伤。这封信一经发表，即引发一场全国范围内关于人生观的大讨论。今天会计界的潘晓也发出了“到底会计人的发展方向在哪里” 之问，他对会计的职业前景充满困惑，大伙给他点拨下！

筱筱-三年时光：我今天去面试了会计，瞬间觉得自己是个废物，虽然有中级也考过了注会，但是在当前的求职行情，真的看到博主发的文章，我一下子哭了，我也想知道财务人出路到底在哪里。
LarryChow：来，老财务告诉你。你觉得难受是因为你刚开始做，沉下心来一直做一直卷，就会成为不可或缺的那个人，这适用于大部分的中小企业。等时间阅历到了，你的薪酬就是一个社会中等偏上的(看个人能力),而且很稳.这就是一个专业技术的工作,要沉淀和积累,所以考证（CPA/CFA/FRM等）是有用的，直接见证书发offer。
喜欢看搞笑视频的打工人：也不是所有的审计狗都能跳槽到甲方当财务经理，甲方自己内部培养土生土长的财务经理比外面来的更吃香。
12345-稀里糊涂：能做到大公司财务总监的人凤毛麟角，建议家里穷改变赛道！去做销售类的工作。不要要在财务这条道走下去，普通财务人只能糊口，温饱都成问题。
馨雅之瑜：我反而觉得做审计还挺适合底层出身的人，自己条件不好，只能靠吃苦啊，难不成靠买彩票中大奖？
属于猫的快乐：吃几年苦少不了，忍忍吧。
花开流年且听风吟：财务的确很难，国企现在财务的位置也在降低，基本都是程序报销，全公司扫单子。财务承担的就是审核，但是做财务分析还是有前途的。
我的少年c6-29：建议继续干，改行也很难！
金陵立水丰：干到后期是拼资源，融资筹资投行背景资源，专业上根本不缺人，永远有人比你优秀且要价低。会计说实话有点技术但是不高，交叉领域可以尝试。找准自己的优势再做职业谋划。
龙卷风静悄悄：除了审计，自己还会什么，这很重要！不是所有审计都能到企业做财务的，特别是企业内审更加难！需要有企业经营的思维才行。
炭烧肥牛：往财务分析，大数据分析方向转吧，业财融合也是这个时代的潮流，同时考证也别落下～选择那些含金量高的考～底层财务人，又吃不了很大的苦，家里又没关系，一眼望到头。
梧桐果子99：我很多同学就是一毕业做审计，都是熬出来的，有啥不能熬，现在也都过得很好。家庭背景不好的，做个技术工种挺好的啊。
时捷1号：如果真的很不喜欢这份工作，那就换一份有相关性的工作；如果找不到，但又很不喜欢现在的，那就趁年轻换个行当转转型；如果还能坚持一下的，那就骑驴找马，机会有的时候说来就来。
凳子上的煤煤虫：审计都这样啊，都是这么熬出来的啊，我同学曾经连着两个月不休息，每天晚上十一二点下班，第二天九点半照常上班，睡觉前还会看半个小时注会的考试书，她父母都是高知，家里根本不缺钱，人家都能吃得了苦，家境底层有什么理由那么娇气啊！
奕歌王：才半年，就忍不了，做财务第一就是要忍耐，财务很多，好的财务很少，也很难，其实第一份工作在事务所还是不错的，如果是大所，年底的年报审计，还是能学到不少，有一定经验积累才好跳。
杨小抠儿：这没有什么好说的，不经一番寒彻骨怎得梅花扑鼻。谁都有过忍辱负重，砥砺前行的经历。受不了可以选择放弃。人生很长，不必一棵树上吊死。但放弃之前请想清楚，普通家庭出身没有随随便便成功，去做别的真的会更好吗？觉得自己难，真的难吗？有父母这代难？再换句话说，父母觉得他们难，有爷爷奶奶这辈难吗？这不是一代一代都这么过来了吗！一点挫折委屈就叫苦不屑，喊自己时运不济、难以承受，那是你自己的问题，社会不欠任何人什么。想好，决定，坚持，没有什么好抱怨的。
Bremen的匹诺曹：评论里说吃不了苦的，我相信没干过审计，不知道连轴转加班什么样。这位朋友的困惑很多人都有，说实话我也想不出来有什么好办法。底层人员真的很难出头。别说无休止的考证，证书可以提高薪资但也不是万能的，内资大多数事务所的持证经理有多少年薪三十以上的？而且年龄大了结婚生子之后谁愿意天天出差。
南小瓜的小南瓜：审计能够接触到的企业那么多，借着这个多了解一下行业信息，多积累一些经验然后再跳槽不是更好么～累，但是真能学到东西呀。
拉屎畅快是人间幸事：审计最优路线是四大做ipo项目积累经验+认识人然后跳槽到金融做项目经理，但是这个基本是一直加班但钱多，财务类是钱少活（相对）少，但没啥发展，想当财务经理（管理岗非干活类的）可能处理人际关系的能力更重要不然就是卷生卷死也没钱。
suicasuki：大学专业是会计，二本。本打算毕业去事务所卷，今年毕业了就上岸事业单位的会计，感觉挺好的，不用卷了大学期间疯狂考证，不知道大家知道acca吗，我已经考了9门了，现在在编制里啥也不想考了，就打算考个初会加加工资。
木头要过CPA：我是在工厂做了几年会计，前两年公司建共享，我就去了，到这里越发觉得基础会计岗会慢慢被信息化智能化替代，缺少都是懂业务、财务、系统的综合性人才。而且跟实施商一起工作的就发现他们业务顾问工资挺高的，项目总监也是财务转型，自学的信息系统。听说现在年薪百万，很牛...
我把回忆删掉了：可以试一下财务BP这个岗位，分析方向的，一般大型制造企业有这个需求，一线城市薪资可以去到1.5w到2w，南京的话估计也有1w+，不过对个人素质要求相对较高，需要具备良好的沟通协调能力，以及熟悉产品制造及供应链（这个可以慢慢学）。
李子红了：现在就业形势比较严峻，你感觉自己辞职后找不到好工作，考公也非常难、不太现实，那就不要轻易辞职。不管干什么工作都不容易，都需要吃苦；学了那么多年的专业，也不能说丢就丢了；再说，你的家庭也不能提供助力，所以，还是要努力调整自己的心态，咬咬牙坚持下去，慢慢积累经验，再寻找新的工作机会。
抽到一只鲨鲨：事务所干不长久的 最终归宿还是企业好。我反倒觉得会计是最好找工作诶 永远不会失业 因为各行各业都需要会计。试着投外企 中外合资还有上市的 国企也试试 有很多条件很好的工作外一就碰上了。好歹也是个硕士，连很多专科会计有经验的也都混的不错，要有点信心。
